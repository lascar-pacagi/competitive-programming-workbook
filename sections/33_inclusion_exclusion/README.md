# Section 33: Inclusion-Exclusion

This section teaches how to count a union of overlapping sets by alternating
additions and subtractions. The local exercises cover subset enumeration,
surjective strings, and bounded stars-and-bars.

## Study Order

1. Read `lesson.qmd`.
2. Attempt the local exercises:
   - `a_multiples_union`
   - `b_all_symbols`
   - `c_bounded_candies`
3. Run the checker:

```bash
python3 sections/33_inclusion_exclusion/check.py
```

To test the reference solutions:

```bash
CP_TARGET=solution python3 sections/33_inclusion_exclusion/check.py
```

4. Read `editorial.qmd`.
5. Work through `PRACTICE.md`.

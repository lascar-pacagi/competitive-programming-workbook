# A. Multiples Union

Given `N` and `m` positive integers `d[1], d[2], ..., d[m]`, count how many
integers `x` with `1 <= x <= N` are divisible by at least one `d[i]`.

## Input

```text
N m
d1 d2 ... dm
```

`1 <= N <= 10^18`, `1 <= m <= 20`, `1 <= d[i] <= 10^18`.

## Output

Print the count.

## Sample

Input:

```text
20 3
2 3 5
```

Output:

```text
14
```

# D. Seating Without Matches

There are `n` people and `n` numbered seats. Person `i` originally sits in seat
`i`. Count seatings in which nobody remains in their original seat, modulo
`1000000007`.

## Input

```text
n
```

`1 <= n <= 1000000`.

## Output

Print the number of valid seatings modulo `1000000007`.

## Sample

```text
4
```

```text
9
```

# Offline companion: ABC339_G -- Smaller Sum

This is an original, locally judgeable companion for [ABC339_G -- Smaller Sum](https://atcoder.jp/contests/abc339/tasks/abc339_g?lang=en). It is **not** a copied AtCoder statement. Solve this package offline to practise a nearby course technique, then solve the linked official task on AtCoder.


For each positive integer `x`, find the smallest positive integer `k` such
that `x * k` is a perfect square.

## Input

```text
q
x1
x2
...
xq
```

`1 <= q <= 200000` and `1 <= xi <= 1000000`.

## Output

Print one answer per query: the smallest positive integer `k` for that query.

## Sample

```text
5
1
12
18
72
36
```

```text
1
3
2
2
1
```

For example, `72 * 2 = 144`, which is a perfect square.

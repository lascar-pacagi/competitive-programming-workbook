# Offline companion: ABC204_E -- Rush Hour 2

This is an original, locally judgeable companion for [ABC204_E -- Rush Hour 2](https://atcoder.jp/contests/abc204/tasks/abc204_e?lang=en). It is **not** a copied AtCoder statement. Solve this package offline to practise a nearby course technique, then solve the linked official task on AtCoder.


There are `n` exhibition booths arranged in a circle. Booth `i` gives reward
`a[i]`. You may select any set of booths, but no two adjacent booths may both
be selected. Booth `1` and booth `n` are also adjacent.

Find the maximum total reward. Selecting no booth is allowed.

## Input

```text
n
a1 a2 ... an
```

`1 <= n <= 200000`, `-10^9 <= ai <= 10^9`.

## Output

Print the maximum possible reward.

## Sample

```text
5
2 7 9 3 1
```

```text
11
```

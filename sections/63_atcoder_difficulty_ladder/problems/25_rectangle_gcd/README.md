# Offline companion: ABC254_F -- Rectangle GCD

This is an original, locally judgeable companion for [ABC254_F -- Rectangle GCD](https://atcoder.jp/contests/abc254/tasks/abc254_f?lang=en). It is **not** a copied AtCoder statement. Solve this package offline to practise a nearby course technique, then solve the linked official task on AtCoder.


An alphabet has `k` symbols, numbered from `1` to `k`.

Count the strings of length `n` in which **every** symbol appears at least
once. Print the answer modulo `1,000,000,007`.

## Input

```text
n k
```

## Constraints

```text
1 <= n <= 10^18
1 <= k <= 20
```

## Output

Print the required number of strings modulo `1,000,000,007`.

## Sample

Input:

```text
3 2
```

Output:

```text
6
```

The six valid strings are `112`, `121`, `211`, `122`, `212`, and `221`.

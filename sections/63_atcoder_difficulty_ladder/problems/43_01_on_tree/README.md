# Offline companion: AGC023_F -- 01 on Tree

This is an original, locally judgeable companion for [AGC023_F -- 01 on Tree](https://atcoder.jp/contests/agc023/tasks/agc023_f?lang=en). It is **not** a copied AtCoder statement. Solve this package offline to practise a nearby course technique, then solve the linked official task on AtCoder.


There are `n` distinct people. Split them into exactly `k` nonempty teams.

Teams have no names: swapping two whole teams does not create a new split.
Print the number of possible splits modulo `1,000,000,007`.

## Input

```text
n k
```

## Constraints

```text
1 <= k <= n <= 2,000
```

## Output

Print the required count modulo `1,000,000,007`.

## Sample

Input:

```text
4 2
```

Output:

```text
7
```

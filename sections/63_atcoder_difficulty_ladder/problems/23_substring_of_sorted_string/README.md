# Offline companion: ABC285_F -- Substring of Sorted String

This is an original, locally judgeable companion for [ABC285_F -- Substring of Sorted String](https://atcoder.jp/contests/abc285/tasks/abc285_f?lang=en). It is **not** a copied AtCoder statement. Solve this package offline to practise a nearby course technique, then solve the linked official task on AtCoder.


There are `n` people and `n` numbered seats. Person `i` originally sits in seat
`i`. Count seatings in which nobody remains in their original seat, modulo
`1000000007`.

## Input

```text
n
```

`1 <= n <= 1000000`.

## Output

Print the number of valid seatings modulo `1000000007`.

## Sample

```text
4
```

```text
9
```

# Offline companion: ARC069_D -- Flags

This is an original, locally judgeable companion for [ARC069_D -- Flags](https://atcoder.jp/contests/arc069/tasks/arc069_d?lang=en). It is **not** a copied AtCoder statement. Solve this package offline to practise a nearby course technique, then solve the linked official task on AtCoder.


Given a lowercase string `s`, print the maximum length of a substring that
occurs at least twice in `s`. Occurrences may overlap.

## Input

```text
s
```

## Constraints

```text
1 <= |s| <= 200000
s contains lowercase English letters
```

## Output

Print one integer: the maximum repeated-substring length. Print `0` if no
nonempty substring occurs twice.

## Sample

```text
banana
```

```text
3
```

`ana` occurs starting at positions 2 and 4; these occurrences overlap.

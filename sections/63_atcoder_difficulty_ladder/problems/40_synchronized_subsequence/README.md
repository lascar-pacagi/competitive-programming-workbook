# Offline companion: AGC026_E -- Synchronized Subsequence

This is an original, locally judgeable companion for [AGC026_E -- Synchronized Subsequence](https://atcoder.jp/contests/agc026/tasks/agc026_e?lang=en). It is **not** a copied AtCoder statement. Solve this package offline to practise a nearby course technique, then solve the linked official task on AtCoder.


For each query `l r`, print `F(l)+...+F(r)` modulo `1,000,000,007`, where
`F(0)=0` and `F(1)=1`.

## Input

```text
q
l1 r1
...
```

`1 <= q <= 200,000`, `0 <= l <= r <= 10^18`.

## Output

One answer per query.

## Sample

```text
3
0 0
0 5
3 7
```

```text
0
12
31
```

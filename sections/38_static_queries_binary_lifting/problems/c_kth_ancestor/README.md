# C. Kth Ancestor

        In a rooted tree with root 1, answer queries asking for the `k`-th ancestor of a node, or `-1` if it does not exist.

        ## Input

        See the operation format described above. All indices are 1-based.

        ## Output

        Print each requested answer in order.

        ## Sample

        Input:

        ```text
        5 5
1 1 2 2
4 1
4 2
4 3
1 0
3 1
        ```

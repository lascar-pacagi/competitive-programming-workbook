# C. Closest Pair

Print the minimum squared Euclidean distance between two distinct input points. Equal coordinates at different indices are allowed.

Input: `n`, then n points. `2 <= n <= 200000`, `|coordinate| <= 10^9`. The answer fits signed 64-bit.

Sample:
```text
4
0 0
5 0
2 2
3 2
```
```text
1
```

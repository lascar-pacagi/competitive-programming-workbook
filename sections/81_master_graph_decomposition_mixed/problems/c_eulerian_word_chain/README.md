# Eulerian Word Chain

Each lowercase word is a directed edge from its first letter to its last. Order all words so consecutive words join. Among valid orders, print the lexicographically smallest sequence of words. Words are distinct.

Input: `n`, then `n` lowercase words; total length <= 200000.

Output the words on one line or `IMPOSSIBLE`.

Sample input
```text
3
ab
ba
ac
```
Sample output
```text
ab ba ac
```

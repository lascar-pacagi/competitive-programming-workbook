# Unique Sink Population

People pass information along directed edges. Print the size of the unique strongly connected component from which no edge leaves to another component. If there is not exactly one such component, print `0`.

Input: `n m`, then directed edges; `n,m <= 200000`.

Sample input
```text
4 4
1 2
2 1
2 3
4 3
```
Sample output
```text
1
```

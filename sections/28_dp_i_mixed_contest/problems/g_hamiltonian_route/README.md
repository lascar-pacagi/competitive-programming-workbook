# G. Hamiltonian Route

A directed cost matrix is given. Starting at vertex `1`, visit every
vertex exactly once and finish at vertex `n`. Entry `-1` means the directed
edge does not exist. Print the minimum cost, or `-1`.

## Input
```text
n
n x n cost matrix
```
`2 <= n <= 18`, other costs are nonnegative.

## Sample
```text
4
-1 1 8 -1
-1 -1 1 9
-1 4 -1 1
-1 -1 -1 -1
```
```text
3
```

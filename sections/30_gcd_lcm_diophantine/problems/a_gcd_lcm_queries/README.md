# A. GCD LCM Queries

For each query, given two positive integers `a` and `b`, print:

```text
gcd(a, b) lcm(a, b)
```

## Input

```text
q
a1 b1
a2 b2
...
aq bq
```

`1 <= q <= 2 * 10^5`, `1 <= a,b <= 10^9`.

## Output

Print one line per query.

## Sample

Input:

```text
3
12 18
7 5
1000000000 1000000000
```

Output:

```text
6 36
1 35
1000000000 1000000000
```

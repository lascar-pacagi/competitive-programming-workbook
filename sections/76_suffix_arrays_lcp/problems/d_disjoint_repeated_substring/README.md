# Disjoint Repeated Substring

Find the greatest `L` for which a lowercase string contains two equal length-`L` substrings with disjoint index intervals. The occurrences may touch but may not overlap.

Input: one string `s`, `1 <= |s| <= 200000`.

Output: the maximum `L`.

Sample input
```text
aaaaa
```
Sample output
```text
2
```

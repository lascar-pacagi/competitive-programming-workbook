# Repeated At Least K Times

Given a lowercase string `s` and an integer `k`, find the maximum length of a substring that occurs at least `k` times. Occurrences may overlap.

Input: `s` and `k` on one line, with `1 <= |s| <= 200000` and `1 <= k <= |s|`.

Output: one integer.

Sample input
```text
banana 2
```
Sample output
```text
3
```

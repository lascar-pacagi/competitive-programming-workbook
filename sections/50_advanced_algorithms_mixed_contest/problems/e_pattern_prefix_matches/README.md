# E. Pattern Prefix Matches

Given lowercase strings `pattern` and `text`, for every text position print
the length of the longest prefix of `pattern` matching the text starting at
that position.

## Input
```text
pattern
text
```
Total length is at most `400000`.

## Sample
```text
aba
abacaba
```
```text
3 0 1 0 3 0 1
```

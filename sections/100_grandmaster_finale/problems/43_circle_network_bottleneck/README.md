# Circle Network Bottleneck

Delaunay sparsification preserves the Euclidean network edges needed by Kruskal.

Given `n <= 2500` planar points, print the total Euclidean length of a minimum spanning tree of the complete geometric graph. No three points are collinear and no four are cocircular.

Sample input
```text
3
0 0
2 0
0 2
```
Sample output
```text
4.0000000000
```

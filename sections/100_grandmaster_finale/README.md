# Section 100: Grandmaster Finale

This final section contains sixty-five Master-to-Grandmaster problems. Problems
01--30 revisit the major course families. Problems 31--65 are new problems,
rated roughly 2500--3300, that each depend on one idea the statement does not
name: algebra and number theory (31--40), geometry and grids (41--49), and a
final gauntlet (50--65).

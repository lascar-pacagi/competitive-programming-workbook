# F. Component Repair

Given an undirected graph, print its number of connected components, the
minimum number of new roads needed to make it connected, and the size of
its largest component.

## Input

```text
n m
u1 v1
...
um vm
```

`1 <= n,m <= 200000`.

## Output

Print `components roads_needed largest_size`.

## Sample

```text
7 4
1 2
2 3
4 5
6 7
```

```text
3 2 3
```

# B. Maximum Subarray Updates

        After each point assignment, print the maximum non-empty subarray sum of the whole array.

        ## Input

        See the operation format described above. All indices are 1-based.

        ## Output

        Print each requested answer in order.

        ## Sample

        Input:

        ```text
        4 3
1 -2 3 4
2 -10
4 -5
1 -1
        ```

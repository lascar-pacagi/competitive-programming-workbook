# K-th Substring With Multiplicity

Form a multiset containing one copy of `s[l..r]` for every index pair `l <= r`. Sort it lexicographically, retaining duplicates. Print its `k`-th element or `IMPOSSIBLE`.

Input: lowercase `s` and `k`, with `|s| <= 200000`, `1 <= k <= 10^18`.

Sample input
```text
aba 3
```
Sample output
```text
ab
```

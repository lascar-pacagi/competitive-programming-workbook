# Repetition Spectrum

For every `k` from `1` through `n`, find the maximum length of a substring occurring at least `k` times in `s`. Occurrences may overlap.

Input: one lowercase string `s`, `1 <= n <= 200000`.

Output: `n` integers.

Sample input
```text
banana
```
Sample output
```text
6 3 1 0 0 0
```

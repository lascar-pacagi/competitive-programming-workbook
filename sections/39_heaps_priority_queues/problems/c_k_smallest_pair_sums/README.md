# C. K Smallest Pair Sums

        Two arrays are sorted. Print the `k` smallest values of `a[i]+b[j]`.

        ## Input

        See the operation format described above. All indices are 1-based.

        ## Output

        Print each requested answer in order.

        ## Sample

        Input:

        ```text
        3 3 5
1 4 8
2 3 10
        ```

# B. Palindrome Repairs

You are given a lowercase string `s`. In one operation, you may insert any
single lowercase letter anywhere in the string.

Find the minimum number of insertions needed to make `s` a palindrome.

## Input

```text
s
```

`1 <= |s| <= 1000`.

## Output

Print the minimum number of insertions.

## Sample

Input:

```text
abcda
```

Output:

```text
2
```

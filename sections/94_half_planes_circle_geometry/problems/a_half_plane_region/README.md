# Half-Plane Region

Each directed line from `A` to `B` keeps the closed half-plane on its left. Compute the area of their intersection. Print `0` if it is empty. The input guarantees that every nonempty intersection is bounded. `n <= 200000`; coordinates have absolute value at most `10^6`.

Sample input
```text
4
0 0 2 0
2 0 2 2
2 2 0 2
0 2 0 0
```
Sample output
```text
4.0000000000
```

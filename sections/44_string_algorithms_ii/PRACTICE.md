# Practice Queue

1. Codeforces 271D - Good Substrings (distinct-substring counting)
   https://codeforces.com/problemset/problem/271/D
2. AtCoder ABC353 E - Yet Another Sigma Problem (trie-prefix aggregation)
   https://atcoder.jp/contests/abc353/tasks/abc353_e
3. Kattis String Multi Matching - ICPC-style dictionary matching
   https://open.kattis.com/problems/stringmultimatching

Choose the representation from the query shape: trie for dictionary prefixes,
exact comparison for small palindrome ranges, and suffix automaton for all
substrings of one large text.

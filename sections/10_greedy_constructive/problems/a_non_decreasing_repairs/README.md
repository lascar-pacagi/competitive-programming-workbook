# A. Non-Decreasing Repairs

## Statement

For each test case, you are given an array `a`. In one operation, you may
increase any element by `1`.

Find the minimum number of operations needed to make the array non-decreasing.

## Input

```text
T
n
a1 a2 ... an
...
```

The sum of `n` over all test cases is at most `200000`.

## Output

For each test case, print the minimum number of operations.

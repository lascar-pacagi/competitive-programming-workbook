# Complete Factorization

Factor each positive unsigned integer `n < 2^64`. Print its prime factors in nondecreasing order, with repetitions. For `n=1`, print `1`. There are at most 200 queries.

Sample input
```text
3
1
60
1000000016000000063
```
Sample output
```text
1
2 2 3 5
1000000007 1000000009
```

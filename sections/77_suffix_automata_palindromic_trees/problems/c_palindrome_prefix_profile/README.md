# Palindrome Prefix Profile

For every nonempty prefix of a lowercase string, print two values: the number of distinct palindromic substrings in that prefix, and the length of its longest palindromic suffix.

Input: one string `s`, `1 <= |s| <= 200000`.

Output: `|s|` lines.

Sample input
```text
ababa
```
Sample output
```text
1 1
2 1
3 3
4 3
5 5
```

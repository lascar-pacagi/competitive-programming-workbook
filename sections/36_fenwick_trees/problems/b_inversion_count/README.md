# B. Inversion Count

        Given an array, count pairs `i < j` with `a[i] > a[j]`. Values may repeat and may be large.

        ## Input

        See the operation format described above. All indices are 1-based.

        ## Output

        Print each requested answer in order.

        ## Sample

        Input:

        ```text
        5
3 1 2 5 4
        ```

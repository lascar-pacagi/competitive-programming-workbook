# Contest protocol

1. Spend the first 20 minutes writing a one-line model and target complexity
   for all six problems.
2. Attempt in any order; do not infer difficulty only from the letter.
3. Before every submission, compare with a brute oracle on tiny random input.
4. After the contest, classify each block as modeling, proof, complexity,
   implementation, or testing debt.

The local checker supports `--problem`, `--lang`, and `--keep-going`, so an
upsolve need not follow contest order.

# N. Square-Free Queries

For each query `x`, count the positive integers `y <= x` that are not divisible
by the square of any prime. Such numbers are called square-free.

There are at most `200000` queries and every `x` is at most `1000000`.

## Input

```text
q
x_1 x_2 ... x_q
```

## Output

Print one answer per query.

## Sample

```text
3
1 10 20
```

```text
1
7
13
```

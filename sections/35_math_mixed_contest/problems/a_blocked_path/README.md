# A. Blocked Path

You move from `(1,1)` to `(H,W)` using only moves down and right. One cell
`(R,C)` is blocked and cannot be visited.

Count valid paths modulo `1,000,000,007`.

## Input

```text
H W R C
```

`1 <= H,W <= 1,000,000`, `1 <= R <= H`, `1 <= C <= W`.

## Output

Print the number of valid paths.

## Sample

Input:

```text
3 3 2 2
```

Output:

```text
2
```

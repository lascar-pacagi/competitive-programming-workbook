# P. Subarray GCD Sum

Given an array `a`, compute the sum of the GCD of every nonempty contiguous
subarray, modulo `1000000007`.

The array length is at most `200000`, and every value is between `1` and
`1000000`.

## Input

```text
n
a_1 a_2 ... a_n
```

## Output

Print one integer.

## Sample

```text
4
2 4 6 3
```

```text
26
```

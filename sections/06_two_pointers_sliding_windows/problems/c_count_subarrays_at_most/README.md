# C. Count Subarrays At Most K

## Statement

For each test case, you are given an array of nonnegative integers and a limit
`k`. Count the number of nonempty contiguous subarrays whose sum is at most
`k`.

## Input

```text
T
n k
a1 a2 ... an
...
```

`1 <= T <= 50`, the total `n` over all test cases is at most `200000`,
`0 <= ai`, and `0 <= k`.

## Output

For each test case, print the number of valid subarrays.

# A. Sum Under Constraints

## Statement

For each test case, you are given an array. Print the sum of its elements.

This is intentionally simple. The point is to respect multiple test cases,
large input, and 64-bit sums.

## Input

```text
T
n
a1 a2 ... an
...
```

`1 <= T`, `1 <= n`, and the total number of array elements over all test cases
is at most `200000`. Each `ai` fits in a signed 32-bit integer, but the sum may
not.

## Output

For each test case, print the sum on its own line.

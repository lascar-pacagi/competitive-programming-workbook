# B. Until Threshold

## Statement

For each test case, you are given positive integers `x` and `y`. One operation
replaces `x` by `2x + 1`. Print the minimum number of operations needed until
`x >= y`.

## Input

```text
T
x y
...
```

`1 <= x, y <= 10^18`.

## Output

For each test case, print the minimum number of operations.

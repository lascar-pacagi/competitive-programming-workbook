# J. Interval Point Cover

Choose the minimum number of integer points so that every closed interval
contains at least one chosen point. Print only that minimum number.

## Input

```text
n
l1 r1
...
ln rn
```

`1 <= n <= 200000`, `-10^9 <= l_i <= r_i <= 10^9`.

## Output

Print the minimum number of points.

## Sample

```text
5
1 3
2 5
3 6
7 8
8 10
```

```text
2
```

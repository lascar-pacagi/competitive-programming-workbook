# A. Complete Window

## Statement

For each test case, you are given an array `a` of length `n` and an integer
`m`. Values from `1` to `m` are required labels. Other values may appear but do
not help.

Find the length of the shortest contiguous subarray that contains every
required label `1, 2, ..., m` at least once. If no such subarray exists, print
`-1`.

## Input

```text
T
n m
a1 a2 ... an
...
```

The sum of `n` over all test cases is at most `200000`.

## Output

For each test case, print the minimum length or `-1`.

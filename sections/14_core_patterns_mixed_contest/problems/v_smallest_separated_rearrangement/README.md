# V. Smallest Separated Rearrangement

Rearrange all characters of a lowercase string `s` so that no two adjacent
characters are equal. Among all valid rearrangements, print the
lexicographically smallest one. If no valid rearrangement exists, print
`IMPOSSIBLE`.

## Input

One lowercase English string `s`.

`1 <= |s| <= 200000`.

## Output

Print the lexicographically smallest valid rearrangement, or `IMPOSSIBLE`.

## Sample Input

```text
aaabbc
```

## Sample Output

```text
ababac
```

# E. Smallest Distinct Subsequence

For each lowercase string, choose a subsequence containing every distinct
character of the string exactly once. Print the lexicographically smallest
possible subsequence.

## Input

```text
T
s1
...
sT
```

The total string length is at most `200000`.

## Output

Print one answer per string.

## Sample

```text
4
cbacdcbc
bcabc
bbcaac
aaaa
```

```text
acdb
abc
bac
a
```

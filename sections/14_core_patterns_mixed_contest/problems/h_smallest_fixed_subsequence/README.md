# H. Smallest Fixed-Length Subsequence

Given a lowercase string `s` and an integer `k`, choose a subsequence of
exactly `k` characters. Print the lexicographically smallest possible one.

## Input

```text
s
k
```

`1 <= k <= |s| <= 200000`.

## Output

Print the selected subsequence.

## Sample

```text
cbacdcbc
4
```

```text
acbc
```

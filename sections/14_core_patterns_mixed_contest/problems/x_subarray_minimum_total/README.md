# X. Subarray Minimum Total

For every nonempty contiguous subarray of an array, take its minimum value.
Print the sum of all these minima.

## Input

The first line contains an integer `n`.

The second line contains `n` positive integers `a[1], a[2], ..., a[n]`.

`1 <= n <= 200000`

`1 <= a[i] <= 1000000`

The answer fits in a signed 64-bit integer.

## Output

Print the sum of the minimum values of all nonempty contiguous subarrays.

## Sample Input

```text
4
3 1 2 4
```

## Sample Output

```text
17
```

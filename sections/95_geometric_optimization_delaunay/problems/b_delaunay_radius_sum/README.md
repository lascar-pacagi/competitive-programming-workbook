# Delaunay Radius Sum

Given `3 <= n <= 2500` planar points with coordinates of absolute value at most `10^9`, print the sum of the circumradii of all triangles in their Delaunay triangulation. No three points are collinear and no four are cocircular, so the triangulation is unique.

Sample input
```text
3
0 0
2 0
0 2
```
Sample output
```text
1.4142135624
```

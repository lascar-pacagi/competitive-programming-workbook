# Euclidean Network

Given `0 <= n <= 2500` planar points with coordinates of absolute value at most `10^9`, print the total Euclidean length of a minimum spanning tree of the complete geometric graph. No three points are collinear and no four are cocircular.

Sample input
```text
3
0 0
2 0
0 2
```
Sample output
```text
4.0000000000
```

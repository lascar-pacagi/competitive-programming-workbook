# Section 61: ICPC Contest Readiness

This final section turns the course's algorithmic toolkit into a repeatable
team-contest process. Start with the ordered 20-problem offline
[ICPC readiness sheet](problem_sheet.pdf), then use [editorial.pdf](editorial.pdf)
only to upsolve. The linked Kattis pages are the authoritative statements and
submission surfaces.

Every rung also has an original local companion package. See
[OFFLINE_COMPANIONS.md](OFFLINE_COMPANIONS.md): each package has a neutral
C++/Python skeleton, both reference implementations, fixed hostile cases,
and a randomized generator. These are original practice problems, not copied
Kattis statements; the Kattis links remain the submission target.

```bash
python3 sections/61_icpc_contest_readiness/check.py
CP_TARGET=solution python3 sections/61_icpc_contest_readiness/check.py
```

The local tasks use the scoring and workflow rules stated in their own
problems. Real regionals can differ, so always read the contest's published
rules before competing.

Blind local practice: `d_penalty_order` (use its README only before the
editorial).

# Section 61: ICPC Contest Readiness

This final section turns the course's algorithmic toolkit into a repeatable
team-contest process. Read the lesson with your team, solve the three local
drills, then run the five-hour simulation from `PRACTICE.md`.

```bash
python3 sections/61_icpc_contest_readiness/check.py
CP_TARGET=solution python3 sections/61_icpc_contest_readiness/check.py
```

The local tasks use the scoring and workflow rules stated in their own
problems. Real regionals can differ, so always read the contest's published
rules before competing.

# Section 13 Practice Queue

For each problem, identify the sort key and explain how the original answer
order is restored.

## Core

1. AtCoder ABC174 F - Range Set Query  
   https://atcoder.jp/contests/abc174/tasks/abc174_f  
   Focus: distinct values in range using offline right endpoints.

2. CSES - Distinct Values Queries  
   https://cses.fi/problemset/task/1734  
   Focus: the same distinct-range pattern with CSES-style constraints.

3. Codeforces 1000C - Covered Points Count  
   https://codeforces.com/problemset/problem/1000/C  
   Focus: offline/event compression over coverage counts.

## Stretch

4. Codeforces 86D - Powerful Array  
   https://codeforces.com/problemset/problem/86/D  
   Focus: Mo's algorithm, an advanced offline ordering of range queries.

## How To Review

For each accepted solution, write:

1. Why is offline reordering legal?
2. What invariant does the data structure satisfy while queries are processed?
3. Where is the original query id stored and restored?

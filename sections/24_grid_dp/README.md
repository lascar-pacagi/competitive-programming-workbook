# Section 24: Grid DP

This section teaches dynamic programming on two-dimensional grids: counting
paths, minimizing path costs, handling blocked cells, and adding direction to
the state when the statement needs it.

## Study Order

1. Read `lesson.qmd`.
2. Attempt the local exercises:
   - `a_safe_paths`
   - `b_lowest_toll`
   - `c_limited_turns`
3. Run the checker:

```bash
python3 sections/24_grid_dp/check.py
```

To test the reference solutions:

```bash
CP_TARGET=solution python3 sections/24_grid_dp/check.py
```

4. Read `editorial.qmd`.
5. Work through `PRACTICE.md`.

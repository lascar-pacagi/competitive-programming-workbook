# B. Frequency Winner

## Statement

For each test case, you are given an array. Print the value that appears most
often. If several values have the same maximum frequency, print the smallest
such value. Also print the frequency.

## Input

```text
T
n
a1 a2 ... an
...
```

`1 <= T <= 50`, the total `n` over all test cases is at most `200000`, and all
values fit in signed 32-bit integers.

## Output

For each test case, print:

```text
value frequency
```

# A. Value Counts

## Statement

You are given an array and then several queries. Each query gives a value `x`.
For each query, print how many times `x` appears in the array.

## Input

```text
T
n q
a1 a2 ... an
x1
x2
...
xq
...
```

`1 <= T <= 50`, the total `n + q` over all test cases is at most `200000`,
and all values fit in signed 32-bit integers.

## Output

For each query, print the count on its own line.

# Earliest Connection

Edges are activated in the given order. For each pair `(u,v)`, print the smallest edge index after which they are connected, or `-1`; a vertex connects to itself at time `0`. `n,m,q <= 200000`.

Sample input
```text
4 3 3
1 2
3 4
2 3
1 4
1 2
2 2
```
Sample output
```text
3
1
0
```

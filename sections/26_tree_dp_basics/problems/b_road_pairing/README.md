# B. Road Pairing

You are given a tree with `n` vertices. Choose as many edges as possible so that
no two chosen edges share an endpoint.

Print the maximum number of chosen edges.

## Input

```text
n
u1 v1
...
u(n-1) v(n-1)
```

`1 <= n <= 2 * 10^5`.

## Output

Print the maximum matching size in the tree.

## Sample

Input:

```text
5
1 2
1 3
3 4
3 5
```

Output:

```text
2
```

# C. Tree Colorings

You are given a tree with `n` vertices. Color every vertex either white or black
so that no two adjacent vertices are both black.

Count the number of valid colorings modulo `1_000_000_007`.

## Input

```text
n
u1 v1
...
u(n-1) v(n-1)
```

`1 <= n <= 2 * 10^5`.

## Output

Print the number of valid colorings modulo `1_000_000_007`.

## Sample

Input:

```text
3
1 2
1 3
```

Output:

```text
5
```

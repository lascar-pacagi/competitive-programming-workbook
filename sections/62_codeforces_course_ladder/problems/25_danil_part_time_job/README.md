# Offline companion: 877E -- Danil and a Part-time Job

This is an original, locally judgeable companion for [877E -- Danil and a Part-time Job](https://codeforces.com/problemset/problem/877/E). It is **not** a copied contest statement. Solve this package offline to practise the course technique, then solve the linked official task on its judge.


Two players alternately take one value from either end of an array. The first
player moves first. Both players play optimally to maximize their own final
sum.

Print the maximum possible value of:

```text
first player's sum - second player's sum
```

## Input

```text
n
a1 a2 ... an
```

`1 <= n <= 3000` and `-10^9 <= ai <= 10^9`.

## Output

Print the final score difference under optimal play.

## Sample

```text
4
1 5 233 7
```

```text
222
```

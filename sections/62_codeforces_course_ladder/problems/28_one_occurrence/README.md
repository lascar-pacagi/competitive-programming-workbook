# Offline companion: 1000F -- One Occurrence

This is an original, locally judgeable companion for [1000F -- One Occurrence](https://codeforces.com/problemset/problem/1000/F). It is **not** a copied contest statement. Solve this package offline to practise the course technique, then solve the linked official task on its judge.


There are `n` exhibition booths arranged in a circle. Booth `i` gives reward
`a[i]`. You may select any set of booths, but no two adjacent booths may both
be selected. Booth `1` and booth `n` are also adjacent.

Find the maximum total reward. Selecting no booth is allowed.

## Input

```text
n
a1 a2 ... an
```

`1 <= n <= 200000`, `-10^9 <= ai <= 10^9`.

## Output

Print the maximum possible reward.

## Sample

```text
5
2 7 9 3 1
```

```text
11
```

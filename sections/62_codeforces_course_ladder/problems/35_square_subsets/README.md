# Offline companion: 895C -- Square Subsets

This is an original, locally judgeable companion for [895C -- Square Subsets](https://codeforces.com/problemset/problem/895/C). It is **not** a copied contest statement. Solve this package offline to practise the course technique, then solve the linked official task on its judge.


An alphabet has `k` symbols, numbered from `1` to `k`.

Count the strings of length `n` in which **every** symbol appears at least
once. Print the answer modulo `1,000,000,007`.

## Input

```text
n k
```

## Constraints

```text
1 <= n <= 10^18
1 <= k <= 20
```

## Output

Print the required number of strings modulo `1,000,000,007`.

## Sample

Input:

```text
3 2
```

Output:

```text
6
```

The six valid strings are `112`, `121`, `211`, `122`, `212`, and `221`.

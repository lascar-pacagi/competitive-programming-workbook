# Offline companion: 240F -- TorCoder

This is an original, locally judgeable companion for [240F -- TorCoder](https://codeforces.com/problemset/problem/240/F). It is **not** a copied contest statement. Solve this package offline to practise the course technique, then solve the linked official task on its judge.


For each query, compute `a^(b^c)` modulo `1000000007`.

## Input

```text
q
a1 b1 c1
...
aq bq cq
```

`1 <= q <= 200000`, `1 <= a <= 1000000006`, and
`1 <= b,c <= 10^18`.

## Output

Print one answer per query.

## Sample

```text
3
2 3 2
5 1 100
1000000006 2 3
```

```text
512
5
1
```

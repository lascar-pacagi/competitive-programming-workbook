# Section 62: Codeforces Course Ladder

This is a 50-problem Codeforces progression from intermediate foundations to
red-level techniques. Start with the offline [problem sheet](problem_sheet.pdf),
solve without opening an editorial, then use [editorial.pdf](editorial.pdf)
only to upsolve.

The sheet contains original concise restatements, input/output contracts, and
visible Codeforces URLs. The official linked page remains the authoritative
statement and submission surface.

Every rung has an original local companion package in
[OFFLINE_COMPANIONS.md](OFFLINE_COMPANIONS.md). Each contains a neutral
C++/Python skeleton, reference solutions in both languages, fixed hostile
tests, and randomized tests. The packages are deliberately not copied
Codeforces statements; solve the linked task separately when you are online.

```bash
python3 sections/62_codeforces_course_ladder/check.py
```

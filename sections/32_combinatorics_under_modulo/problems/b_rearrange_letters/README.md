# B. Rearrange Letters

Given a lowercase string `s`, count how many distinct strings can be formed by
rearranging all its letters. Print the answer modulo `1,000,000,007`.

## Input

```text
s
```

`1 <= |s| <= 1,000,000`, and `s` contains lowercase English letters only.

## Output

Print the number of distinct rearrangements.

## Sample

Input:

```text
aab
```

Output:

```text
3
```

# Low-Cost Fiber

Given `0 <= n <= 2500` planar stations with coordinates of absolute value at most `10^9`, print the total Euclidean length of a minimum-length fiber network of the complete geometric graph. No three stations are collinear and no four are cocircular.

Sample input
```text
3
0 0
2 0
0 2
```
Sample output
```text
4.0000000000
```

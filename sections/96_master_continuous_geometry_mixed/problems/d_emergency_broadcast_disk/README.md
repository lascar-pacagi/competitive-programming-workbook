# Emergency Broadcast Disk

Given `1 <= n <= 200000` emergency sites with coordinates of absolute value at most `10^9`, print the center and radius of their smallest broadcast disk. Output `cx cy r`.

Sample input
```text
3
0 0
2 0
0 2
```
Sample output
```text
1.0000000000 1.0000000000 1.4142135624
```

# Range K-th Value

Given an integer array, answer static queries `(l,r,k)`: print the k-th smallest value in `a[l..r]`. Input: `n q`, the array, then queries; `n,q <= 200000`, values fit signed 32-bit, indices are 1-based.

Sample input
```text
5 3
5 1 4 2 3
1 5 3
2 4 1
3 5 2
```
Sample output
```text
3
1
3
```

# B. Sliding Window Maximum

## Statement

For each test case, given an array `a` and a window size `k`, output the maximum
value in every contiguous window of length `k`.

## Input

```text
T
n k
a1 a2 ... an
...
```

The sum of `n` over all test cases is at most `200000`.

## Output

For each test case, print `n-k+1` integers.

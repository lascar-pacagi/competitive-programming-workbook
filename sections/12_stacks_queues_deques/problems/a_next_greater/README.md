# A. Next Greater

## Statement

For each test case, given an array `a`, output for every position the first
value strictly greater than `a_i` that appears to its right. If no such value
exists, output `-1` for that position.

## Input

```text
T
n
a1 a2 ... an
...
```

The sum of `n` over all test cases is at most `200000`.

## Output

For each test case, print `n` integers.

# C. Shortest Subarray At Least K

## Statement

For each test case, given an array `a` that may contain negative values and an
integer `K`, find the length of the shortest nonempty contiguous subarray with
sum at least `K`. If no such subarray exists, print `-1`.

## Input

```text
T
n K
a1 a2 ... an
...
```

The sum of `n` over all test cases is at most `200000`.

## Output

For each test case, print the minimum length, or `-1`.

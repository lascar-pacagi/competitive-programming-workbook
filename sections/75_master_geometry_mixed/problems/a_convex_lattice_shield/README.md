# A. Convex Lattice Shield

Build the strict convex hull of the given lattice points. Print its doubled area and the number of lattice points on its boundary.

Input: `n`, then n integer points. `3 <= n <= 200000`. The hull has positive area.

Sample:
```text
5
0 0
4 0
4 2
0 2
2 1
```
```text
16 12
```

# Two-Map Forest

Two maps share `n` labeled vertices. Candidate link `i` joins `(a_i,b_i)` on the first map and `(c_i,d_i)` on the second. Decide whether some `n-1` links form a spanning tree on both maps. `n <= 150, m <= 60`.

Sample input
```text
3 3
1 2 1 2
2 3 2 3
1 3 1 3
```
Sample output
```text
YES
```

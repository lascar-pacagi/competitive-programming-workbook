# Cut Threshold Pairs

For each threshold `x`, count unordered vertex pairs whose minimum separating
cut has capacity at most `x`. Use a connected undirected capacitated graph;
`n <= 80`, `m <= 1000`, `q <= 200000`, and capacities are positive.

Sample input
```text
3 3 3
1 2 4
2 3 2
1 3 3
4
5
6
```
Sample output
```text
0
2
3
```

# C. Subarray Sum Count

## Statement

For each test case, count the number of nonempty contiguous subarrays whose
sum is exactly `k`.

## Input

```text
T
n k
a1 a2 ... an
...
```

`1 <= T <= 30`, the total `n` over all test cases is at most `200000`, and
array values fit in signed 32-bit integers.

## Output

For each test case, print the number of subarrays with sum `k`.

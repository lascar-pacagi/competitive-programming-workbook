# Section 29: Modular Arithmetic

This section starts the math phase with the arithmetic tools that appear
constantly in Codeforces, AtCoder, and ICPC problems: safe remainders, fast
power, modular inverse under a prime modulus, and repeated transformations.

## Study Order

1. Read `lesson.qmd`.
2. Attempt the local exercises:
   - `a_power_queries`
   - `b_fraction_queries`
   - `c_affine_repeater`
   - `d_nested_power_queries` (blind practice: use its README only)
3. Run the checker:

```bash
python3 sections/29_modular_arithmetic/check.py
```

To test the reference solutions:

```bash
CP_TARGET=solution python3 sections/29_modular_arithmetic/check.py
```

4. Read `editorial.qmd`.
5. Work through `PRACTICE.md`.

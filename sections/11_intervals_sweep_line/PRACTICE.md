# Section 11 Practice Queue

Use this queue after the local exercises. For each problem, write the event
types and tie order before coding.

## Core

1. Codeforces 1000C - Covered Points Count  
   https://codeforces.com/problemset/problem/1000/C  
   Focus: coverage count over compressed gaps, integer closed segments.

2. AtCoder ABC221 D - Online games  
   https://atcoder.jp/contests/abc221/tasks/abc221_d  
   Focus: half-open login intervals and days with exactly `k` active users.

3. Kattis - Interval Scheduling  
   https://open.kattis.com/problems/intervalscheduling  
   Focus: interval reasoning under ICPC-style input; compare with greedy
   Section 9 and endpoint conventions from this section.

## Stretch

4. CSES - Restaurant Customers  
   https://cses.fi/problemset/task/1619  
   Focus: peak active count with arrivals and departures.

## How To Review

For each problem, record:

1. Are intervals open, closed, or half-open?
2. What happens when start, end, and query events share a coordinate?
3. Is the answer updated on events or on gaps between events?

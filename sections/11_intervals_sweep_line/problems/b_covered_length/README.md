# B. Covered Length

## Statement

For each test case, you are given `n` half-open intervals `[l_i, r_i)`, where
`l_i < r_i`.

Find the total length covered by at least one interval.

## Input

```text
T
n
l1 r1
l2 r2
...
ln rn
...
```

The sum of `n` over all test cases is at most `200000`. Coordinates fit in
signed 64-bit integers.

## Output

For each test case, print the total covered length.

# Compatibility Pairing

Each participant has an integer skill. Two participants may pair exactly when
the absolute difference of their skills belongs to a given allowed set. Print
the maximum number of pairs. `n <= 500`, and the allowed set contains at most
`200000` values.

Sample input
```text
5 2
1 4 6 7 10
2 3
```
Sample output
```text
2
```

# Forbidden Profit Assignment

There are `n` agents and `m` projects (`n <= m <= 350`). Entry `-1` forbids an assignment; otherwise it is a nonnegative profit. Assign every agent a distinct allowed project and maximize profit, or print `IMPOSSIBLE`.

Sample input
```text
2 3
5 -1 4
2 7 3
```
Sample output
```text
12
```

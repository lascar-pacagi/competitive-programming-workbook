# All-Pairs Cut Queries

A connected undirected capacitated multigraph is fixed. For each `(u,v)`, print the minimum capacity of an edge cut separating them. `n <= 80`, `m <= 1000`, `q <= 200000`; capacities are positive.

Sample input
```text
3 3 2
1 2 4
2 3 2
1 3 3
1 2
1 3
```
Sample output
```text
6
5
```

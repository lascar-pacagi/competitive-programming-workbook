# Directed Arborescence

Find the minimum total weight of a directed spanning arborescence rooted at vertex `r`: every other vertex has exactly one selected incoming edge and is reachable from `r`. Print `IMPOSSIBLE` if none exists. `n <= 500`, `m <= 10000`; weights may be negative.

Sample input
```text
3 4 1
1 2 5
1 3 4
2 3 1
3 2 2
```
Sample output
```text
6
```

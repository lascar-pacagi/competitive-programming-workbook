# Two-Edge Connectivity Completion

A connected undirected multigraph is given. Add the fewest new edges between distinct vertices so that the resulting graph has no bridge. Parallel new edges are allowed.

Input: `n m`, followed by edges; `n,m <= 200000`.

Output the minimum number of edges.

Sample input
```text
4 3
1 2
2 3
3 4
```
Sample output
```text
1
```

# Practice order

1. A. GCD Pair Energy -- derive the identity before coding.
2. B. Summatory Totient -- trace the equal-quotient intervals by hand.
3. C. LCM Pair Spectrum -- write the exact meaning of both arrays.
4. D. Square-Free Rank -- blind exercise; budget at least 75 minutes.

For every problem, also write a brute-force oracle for values below 50. At
master+ level, the optimized implementation is often easier to type than it is
to validate; the oracle is part of the solution process.
